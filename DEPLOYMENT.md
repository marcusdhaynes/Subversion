# Subversion

The original interface is hosted directly at https://marcusdhaynes.github.io/Subversion/. It connects to the existing cloud server for translation, server-side project storage and real-time collaboration. The complete source is in this repository. See HOSTING.md for runtime configuration.

The Native builds workflow packages the same interface for Windows, macOS, Linux and Android. iOS source can be initialized on macOS; device distribution requires Apple signing.
